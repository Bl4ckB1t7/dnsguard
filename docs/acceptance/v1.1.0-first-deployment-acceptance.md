## Web 初始化说明

现有 Docker 初始化向导回归测试 `./tests/docker-initialization-wizard.sh`
已通过（3/3），并验证 Bootstrap Token、并发初始化、发布门禁和容器重建。
其中该既有脚本使用兼容模式；全局模式的“分阶段首次部署”由本次隔离 BIND
顺序测试和 Go 单元测试覆盖，未将旧脚本结果冒充为全局模式 Web 联调通过。

首次全局 DENY 上线必须：

1. 准备并审核白名单 JSON；
2. 用 `RPZ_GLOBAL_DENY_SETUP_DEFERRED=true` 完成首次初始化（递归拒绝检查会明确为 `NOT RUN`）；
3. 核对并发布白名单，确认 Primary/Secondary 同步；
4. 由 BIND 管理员把 deny Zone 加入 `response-policy`；
5. 重新执行只读递归检查并移除临时变量。

已完成初始化的服务重启时会拒绝继续使用临时变量，避免把未完成的分阶段配置误当成正式状态。

## 结论

隔离 BIND 的业务连续性和启用顺序验收通过；DO=1 查询外传风险仍然存在，不能将本次
结果宣传为彻底阻断所有 DNS 隧道外传。因此本次结论为 **CONDITIONAL GO**，可供代码审计，
但生产上线前仍需在目标递归 BIND 配置下独立完成 DO=0/DO=1 和上游观测验收。
