## 关键过程说明

初始化第一次完成提交因临时 Secondary Serial 尚未追平返回 HTTP 422，未创建半初始化状态；等待同步后重试返回 HTTP 200。该结果证明初始化门禁未把短暂同步延迟误报为成功。
