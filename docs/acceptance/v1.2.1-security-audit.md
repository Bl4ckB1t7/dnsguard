已保留安全结论：NXDOMAIN 只说明客户端响应，不证明完整 QNAME 未到达上游。生成包现在明确使用 `qname-wait-recurse no break-dnssec yes`；在本次隔离 BIND 9.20 profile 的 24 个拒绝矩阵查询中未观察到上游 QNAME，但旧 profile 的外传结果仍保留为回归证据。`break-dnssec yes` 允许 RPZ 重写带 DNSSEC 数据的响应，并不关闭 DNSSEC 验证；其他递归器、配置和公网 DNSLog 仍未验证，不能宣称通用阻断。
