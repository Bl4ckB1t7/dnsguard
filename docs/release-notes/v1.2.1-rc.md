# DNSGuard v1.2.1 Release Candidate（未发布）

> 本文件是候选版本草稿。v1.2.1 尚未创建 Tag 或 GitHub Release；不得用于生产版本安装。

## 候选范围

- 修复下载的 RPZ 配置包应用后未进入实际加载的 named.conf 的问题。
- 配置包应用保持 preview/check → apply → verify 顺序：--check 只读，--apply 备份并原子更新管理员指定的 BIND_NAMED_CONF，不 reload/restart BIND。
- 真实隔离 E2E 覆盖 Web 下载 ZIP、宿主机 Bash 应用、容器内最终 named-checkconf -z、两个 RPZ Zone 加载、白名单发布、Global Deny 延迟启用和收尾。
- 测试配置使用稳定目录挂载（包含 /etc/bind、/var/lib/bind、/var/cache/bind、/var/log/bind），避免只读单文件挂载造成的 inode 误判。
- 使用真实 `v1.1.1` tag 的独立 Docker 升级、故障中断和快照回滚演练通过；旧版本不会被要求读取候选专属新格式。
- 使用 IANA 当前 1,436 条 TLD 快照的隔离兼容验收通过，脚本校验实际输入数量并记录 SHA256。

## 安全边界

- BIND Primary/Secondary 仍由管理员独立部署；DNSGuard 不通过 SSH、Docker Socket 或其他方式修改生产 BIND。
- Global Deny 只能在白名单发布且所有 Secondary 同步后启用。
- 客户端收到 NXDOMAIN 不等于完整 QNAME 未到达上游；DNSSEC DO=1 的外传风险仍需按目标 BIND 配置单独验证，本候选不宣称百分之百阻断 DNS 隧道。
- 公网 DNSLog 和独立公网来源验证未执行（NOT RUN）；隔离受控上游观察不能替代公网证据。

## 候选门禁

当前建议：**NO-GO**。核心隔离 E2E、升级/回滚和 1,436 条 IANA TLD 兼容验收通过；独立公网可达性、公网 DNSLog，以及所有目标配置下的 DNSSEC DO=1 外传结论仍未完成，移动/平板完整视觉回归也未运行。
